# Pia

Permanent app URL: https://pomoluf.github.io/pia/

Starred home for all Pia work. Everything new (prototypes, designs, builds, links) lives in this repo under simple folders.

## Folders

| Path | What |
|------|------|
| `/` | Live chat shell (`index.html`, `css/`, `js/`) |
| `/refs/` | Style & avatar prototypes (numbered) |
| `/references.html` | Overview of the five style references |

## Quick prototype links

- Soft-3D → photorealistic: https://pomoluf.github.io/pia/soft3d.html

- Cel-shaded full body: https://pomoluf.github.io/pia/celshade.html (upload in progress)
- Style references: https://pomoluf.github.io/pia/references.html

## Naming

Keep paths short and obvious. Prefer `refs/NN-short-name.html` for experiments and a short root alias (`soft3d.html`, `celshade.html`) when a link must be easy to paste.
